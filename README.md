# EDCalculatorProject

Простой калькулятор на Java с базовой арифметикой, защитой от некорректных операций и автоматизированными тестами. Проект собран через Maven и протестирован с помощью **TestNG**.

## Функционал

Калькулятор (`edet.Calculator`) реализует четыре базовые операции над числами типа `double`:

- **Сложение** (`sum`)
- **Вычитание** (`sub`)
- **Умножение** (`multiply`)
- **Деление** (`divide`)

### Особенности реализации

- **Защита от деления на ноль**: при попытке деления на `0` или `-0.0` выбрасывается `ArithmeticException` с сообщением «Деление на ноль запрещено».
- **Контроль неопределённых результатов**: если результат операции — `NaN` (например, `0/0` или `sqrt(-4)`), выбрасывается `ArithmeticException` с сообщением «Математически неопределённый результат (NaN)».
- **Контроль выхода за пределы точных вычислений**: если модуль результата превышает `MAX_SAFE_INTEGER` (2^{53}-1), выбрасывается `ArithmeticException` с сообщением «Результат выходит за пределы точных вычислений». Это нужно, чтобы избежать потери точности, характерной для типа `double`.
- **Округление и нормализация**: для значений, которые укладываются в диапазон `MAX_SAFE_INTEGER`/10^{10}  чисел, применяется округление до 10 знаков после запятой и возврат в виде `long`, если дробная часть равна нулю.
- **Единый тип возврата**: все методы возвращают `Number` (может быть `Double` или `Long` в зависимости от результата).

## Реализованная функциональность

Класс `Calculator` поддерживает четыре базовые операции (`add`, `subtract`, `multiply`, `divide`) и включает следующие архитектурные решения:

* **Умное приведение типов (`Number`).** Если результат вычисления является целым числом, метод возвращает `Long` (без дробного хвоста `.0`). Если результат дробный — возвращается `Double`.
* **Устранение погрешности `double`.** Перед проверкой на целочисленность выполняется очистка двоичных артефактов стандарта IEEE 754 до 10 знаков после запятой (например, `0.29 * 100` корректно возвращает `29L`, а не `28.999999999999996`).
* **Обработка граничных значений и ошибок:**
  * При делении на `0.0` или `-0.0` выбрасывается `ArithmeticException`.
  * При переполнении типа `double` (`Infinity`) или передаче некорректных значений (`NaN`) также выбрасывается `ArithmeticException`.

## Покрытие тестами (`CalculatorTest`)

Автотесты написаны с использованием параметризации (`@DataProvider`) и охватывают:
* **Позитивные сценарии:** операции с положительными, отрицательными, нулевыми и дробными числами.
* **Проверку типов данных:** подтверждение того, что целые результаты возвращаются как `Long`, а дробные — как `Double`.
* **Граничные значения:** обработка периодических дробей (`10.0 / 3.0`) с учетом допустимой погрешности (`delta = 1e-9`) и работа с отрицательным нулем (`-0.0`).
* **Негативные сценарии:** проверка выброса `ArithmeticException` при делении на ноль, переполнении `Double.MAX_VALUE` и передаче `NaN` / `Infinity`.

## Инструкция по запуску тестов

1. Клонируйте репозиторий на локальную машину:
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. Запустите прогон тестов через Maven:
   ```bash
   mvn clean test
   ```

*(Если вы используете Gradle, замените команду запуска на `./gradlew test` и обновите раздел «Стек технологий»).*
